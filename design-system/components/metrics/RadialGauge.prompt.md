Radial donut gauge with the percentage centered — adoption rates, RPC share, coverage.

```jsx
const { RadialGauge } = window.RazorReaperConsoleDesignSystem_40e0a6;
<RadialGauge ratio={0.74} title="Version adoption" sub="162 of 220 on 1.6.x" />
```

- Accent stroke with a soft drop-shadow glow; the fill animates (0.8s smooth ease) on mount/update.
- Track is `--surface-3`; number is Space Grotesk.
