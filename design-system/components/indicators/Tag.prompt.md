Squared mini-chip for configuration values ("UTC fixed", "D1", "Active-first") plus the standard loading spinner.

```jsx
const { Tag, Spinner } = window.RazorReaperConsoleDesignSystem_40e0a6;
<Tag>UTC fixed</Tag>
<Tag accent>Active-first</Tag>
<Spinner small />
```

- Tags are squared (6px radius) to read as "machine value", unlike pill badges which read as "state".
